# team-30

## Project
Edge-Case Miner turns one plain-English request into a verified, labelled video dataset for
physical-AI teams. It searches the archive, checks every clip with Cosmos Reason, reports coverage
gaps, and re-ingests with a better prompt when too little is found.

**Stack:** VSS retrieval and re-ingest skills, Cosmos3-Reason (verification, labels), Cosmos Embed1 (search), YOLO11 (quality), W&B serverless inference (planning, prompts, reports), Python, FastAPI
**Code:** https://github.com/henrihjm/edgecase-miner
**Live app:** none
